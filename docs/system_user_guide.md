# 映鉴使用与演示手册

本文描述当前本地人物审核系统的实际操作，不包含产品讨论过程或尚未实现的规划。

## 1. 系统用途

选择本地媒资与核查人物后，系统检索疑似出镜、关联连续候选并整理证据。审核人员播放片段、对照参考照片，确认、排除或留待复核，最后导出本次审核记录。

人物库中的演员是测试检索对象，不因入库而被定义为敏感人物。机器候选不等于已确认身份。当前只检查人物画面，文字、语音、场景行为及剧情内容尚未参与自动检查。

## 2. 启动与工作空间

macOS 双击项目根目录的 `start.command`，或执行 `./scripts/start_showcase.sh`。等待终端显示地址，打开[算法验证大盘](http://127.0.0.1:8770/?workspace=validation#/overview)。保持启动终端打开，结束后按 Ctrl+C；再次启动保留审核记录，不会自动恢复初始状态。

首次启动显示“准备您的审核工作空间”，可选择：

- 导入内置素材：加入精选视频、人物库和待复核任务；默认照片停用状态保留。
- 导入自己的视频：从文件选择器多选 MP4，查看逐文件进度和成功/失败结果；不会发送到云端。
- 暂不导入：先进入空白工作空间，稍后从媒资库继续导入。

已有工作空间不强制重新初始化。媒资库常驻“导入素材”按钮，可以随时追加；重复导入内置包不会覆盖人工修改，同一上传视频按文件内容去重。批量导入部分失败时，成功项保留，只需重试失败项。

| 空间 | 用途 |
| --- | --- |
| 算法验证 | 验证参考照片与检索效果；默认片段和任务在此，结果不作为正式审核结论 |
| 生产审核 | 仅可选择已启用、至少有两张可用参考照片且已记录“验证通过”结论的人物；默认人物均待验证，所以生产任务为空属正常情况 |

两种空间是任务用途筛选，不是账号或租户隔离。人物库仍为当前运行环境共用，不要为了演示而将人物批量设为已启用。

## 3. 页面分工

| 页面 | 主要用途 |
| --- | --- |
| 审核大盘 | 查看当前积压、趋势、任务状态、人工判断分布、近期完成和需要关注的任务 |
| 审核工作台 | 按任务汇总未处理与留待复核片段，直接继续人工复核 |
| 任务中心 | 查看任务范围、执行状态和人工进度，开始检查或处理失败 |
| 媒资中心 | 搜索和播放本地视频，查看关联任务或从媒资上下文新建任务 |
| 审核对象库 | 分别管理人物、敏感词和内容规则；人物详情中维护参考照片、验证结论与启用状态 |
| 审核结果 | 查阅已完成任务、人物结论、确认片段和完整处理记录，并导出 |
| 技术验证 | 算法验证空间中的维护入口，不属于审核人员日常主流程 |

媒资库展示已导入的默认片段及用户视频。文件选择器导入支持 MP4，单文件最大 20 GB，建议 H.264 编码；校验可解码后复制到系统管理目录，导入本身不执行识别。首次只导入自己的视频时，还需在人物库新增对象并上传参考照片，再创建人物任务。保留的视频编码未被自动转换，浏览器不能播放某些编码时需先转为兼容 MP4。

新任务只从媒资中心选择系统已管理的本地视频，避免把绝对文件路径暴露给审核人员。需要新增视频时先使用“导入媒资”。

## 5. 演示步骤

1. 打开媒资库，搜索“牧马人”，播放一段本地视频。
2. 从审核工作台点击“继续复核”，展示已生成的真实检查结果，无需现场等待整片分析。
3. 播放上下文，对照参考照片，展示定位截图与视频切换。
4. 根据实际判断确认、排除或留待复核，按需填写原因和备注。不能为展示完成率随意确认。
5. 打开人物库，展示多张参考图和已停用照片，说明照片质量及跨年龄差异会影响结果。
6. 返回媒资库，点击“新建检查任务”，选择一个或多个人物，提交真实检查并观察状态。
7. 处理完所有线索后完成审核、导出记录；仍有疑点则保留待复核状态。

首次播放可能需要等待本地转码；系统会缓存预览。复核页默认静音，可手动开启声音，但台词没有经过语音自动审核。

## 6. 任务与复核操作

### 创建与重新检查

填写名称，选择本地视频及人物后提交。只有“人物画面”可用，其余能力标为“暂未启用”。同一服务当前一次执行一个人物检查任务，忙碌时需等待，不提供自动批量调度队列。

已有结果需要重跑时使用“保留记录，重新检查”，系统新建任务并保留原结果。新任务采用当时的人物库状态，不保证与旧结果一致。

### 判断与原因

- 确认出现：通过视频和参考照片确认目标人物出镜。
- 排除：认为不是目标人物，按需记录排除依据。
- 留待复核：画面不清楚或依据不足，不能当作确认结果。
- 撤回复核：恢复为未处理，同时保留操作历史。

可选原因包括人工对照确认、不是目标人物、画面不清楚、需要更多上下文、其他；支持补充备注。判断与原因应一致。

### 快捷操作

| 按键 | 操作 |
| --- | --- |
| 空格 | 播放或暂停 |
| ← / → | 上一条或下一条 |
| 1 / 2 / 3 | 确认、排除、留待复核 |
| 0 | 撤回复核 |

输入框、下拉框和弹窗中不触发全局快捷键；播放器原生控件可能优先处理按键。

### 完成与导出

有未处理或留待复核线索时不能完成审核；明确检测到覆盖不完整时也不能完成。完成时系统保存只读的审核版本快照。若要修改已完成结论，需在结果页填写原因重新打开审核；原版本不会被覆盖。HTML 导出包含媒资、检查范围、任务用途、处理结果、位置、原因和备注。未完成任务已有结果时也可导出，记录会注明尚未完成。

“完成审核”只表示本任务范围内的线索已处理，不代表文字、台词、剧情或未召回内容已通过审核。零候选不是整片安全结论。

## 7. 效果解释与注意事项

82 条是机器候选数量，不是 82 次正确识别。候选可能误报、重复，也可能漏检；当前没有完整独立真值，不应承诺准确率或召回率。

评估效果需要独立于候选选择的片段或整片标注，分别统计正确命中、误报和漏检。这批精选片段不能替代全片测试，方法见[跨媒资验证协议](multi_asset_actor_validation_protocol.md)。

原 8766 环境与 8770 演示环境分别保存数据，不自动同步。不要移动正在使用的视频或随意修改默认包。启动、迁移、备份和故障处理见[部署维护手册](system_operations.md)。
